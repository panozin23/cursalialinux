QUÉ ES ESTO
-----------
La versión de cursalialinux construida sobre DEBIAN con la herramienta
"live-build". Es la versión LIMPIA y apta para COMERCIALIZAR
(a diferencia de la de Ubuntu, que tiene trabas de licencia de Canonical).

DOS EDICIONES (dos ISOs separados):
  - cursalialinux Ligera  → escritorio XFCE  → PCs VIEJAS (rápido, ligero)
  - cursalialinux Moderna → escritorio KDE   → PCs NUEVAS (moderno, bello)
Comparten la MISMA base Debian y la MISMA marca Azul Hielo; solo cambia
el escritorio.

CÓMO RECONSTRUIR (en una laptop con Linux)
------------------------------------------
  1. Instalar herramientas:
       sudo apt install -y live-build debootstrap debian-archive-keyring \
            squashfs-tools xorriso
  2. Extraer la receta:
       tar -xf recetas-live-build/config-ligera-xfce.tar
  3. Entrar a la carpeta y construir:
       cd ligera-xfce
       chmod +x config/hooks/normal/*.hook.chroot
       sudo lb build
  4. Sale un archivo .iso → verificar en máquina virtual → grabar a USB.
  (La edición Moderna/KDE es la misma receta cambiando el escritorio a KDE.)


LICENCIA / COMERCIAL
