GRABAR A USB:
  sudo dd if=cursalialinux-ligera-1.0.iso of=/dev/sdX bs=4M status=progress oflag=sync

RECONSTRUIR (receta liviana):
  sudo apt install -y live-build debootstrap debian-archive-keyring squashfs-tools xorriso grub-pc-bin grub-efi-amd64-bin mtools
  tar -xf recetas-live-build/config-ligera-xfce.tar   (o config-moderna-kde.tar)
  cd al proyecto; sudo lb build   (instala el sistema)
  Luego armar el ISO con grub-mkrescue (el arranque de live-build viejo está roto).
  NOTA: live-build de Ubuntu necesita parches para trixie (ver notas del proyecto).
