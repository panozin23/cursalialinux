Repositorio de cursalialinux

Aquí se publican las mejoras de cursalialinux. Una vez añadido, tu sistema recibe las novedades con apt upgrade, sin reinstalar nada.

Añadirlo a tu sistema

Copia y pega esto en una terminal. Solo hace falta una vez:

sudo mkdir -p /usr/share/keyrings
wget -qO- https://panozin23.github.io/cursalialinux/cursalialinux-archive-keyring.gpg \
  | sudo tee /usr/share/keyrings/cursalialinux.gpg > /dev/null

echo "deb [signed-by=/usr/share/keyrings/cursalialinux.gpg] https://panozin23.github.io/cursalialinux trixie main" \
  | sudo tee /etc/apt/sources.list.d/cursalialinux.list

sudo apt update
sudo apt install cursalialinux-escritorio

Recibir mejoras

sudo apt update && sudo apt upgrade

¿Qué contiene? El Centro cursalialinux, el Windows Studio, la marca, la limpieza automática y la documentación en español.

Todo es software libre, construido sobre Debian, KDE, GNU y decenas de proyectos más.
